# SWAAP: Stealthy World Model Manipulation via Data Poisoning

Repository for the software accompanying the NeurIPS 2026 paper **“Stealthy World Model Manipulation via Data Poisoning”** by Yibin Hu and Zizhan Zheng.

## Release status

The source code, reproduction instructions, and downloadable research assets are being prepared for public release. **They are not yet available in this repository.** Licensing, attribution, and redistribution checks are in progress.

This page reserves the permanent project URL. Once approved, the code-only source release and separately hosted reproduction assets will be added here.
